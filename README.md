# 公平事务所

一款像素风格的 PM 模拟器游戏，玩家将扮演项目负责人，通过决策来管理团队好感度和项目进度。

## 核心玩法

### 好感度系统
- 团队成员各有独立的好感度（0-100）
- 每次决策会影响不同成员的好感度
- 过低的好感度可能导致团队解散

### 满意度系统
- 甲方满意度需要维持在一定水平
- 满意度低于 65 持续 3 周将触发游戏失败
- 满意度颜色指示：绿色(80-100) / 黄色(65-79) / 橙色(50-64) / 红色(0-49)

### 随机事件
- 每周会遇到不同的项目事件
- 每个事件有多个选项，带来不同的结果
- 事件会影响好感度、进度或满意度

### PRD 版本管理
- 每次决策会更新 PRD 版本号
- 完整记录所有变更历史
- 版本号格式：Vx.y.z

### 多结局系统
- 根据最终状态判定不同结局
- 包括完美收官、梦想实现、中规中矩、团队解散、被大厂吞并等结局

## 数据结构

游戏采用数据驱动设计，所有文本内容存储在 `data/` 目录下的 JSON 文件中：

- `data/weekly_reports.json` - 周报模板库
- `data/prd_templates.json` - PRD 变更模板
- `data/events.json` - 随机事件库
- `data/characters.json` - 角色设定
- `data/endings.json` - 结局定义

## 开发原则

1. **数据驱动**：所有文本内容与代码分离，便于扩展和翻译
2. **MVP 优先**：先实现核心玩法，再逐步扩充内容
3. **像素风格**：保持统一的复古 CRT 显示器视觉效果
