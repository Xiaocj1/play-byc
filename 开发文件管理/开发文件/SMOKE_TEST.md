# 公平事务所 · 冒烟测试文档

## 一、基础流程

### 1.1 首页与开始游戏

- [ ] 首页加载正常，无控制台 Error
- [ ] 点击"开始游戏"后正确跳转到 select.html
- [ ] 首次打开显示创始人手记弹窗
- [ ] 点击"开始创业"后弹窗关闭，显示方向选择
- [ ] 再次点击"开始游戏"仍显示创始人手记

### 1.2 创业方向选择

- [ ] 三个方向按钮（To B / To C / B2C）均可见
- [ ] 点击 To B 显示 To B 方向介绍弹窗
- [ ] 点击 To C 显示 To C 方向介绍弹窗
- [ ] 点击 B2C 显示 B2C 方向介绍弹窗
- [ ] 点击"确认选择"后正确跳转到 game.html

### 1.3 游戏主界面

- [ ] 顶部状态栏显示：周数、预算、方向标识
- [ ] 顶部状态栏显示：名声、负债、满意度（如适用）
- [ ] 主内容区显示：当前事件标题和描述
- [ ] 底部工具栏按钮均可点击

### 1.4 事件系统

- [ ] 每周显示一个随机事件
- [ ] 事件描述正常显示
- [ ] 每个选项按钮可点击
- [ ] 点击选项后数值正确变化
- [ ] To B 专属事件仅在 To B 方向出现
- [ ] To C 专属事件仅在 To C 方向出现
- [ ] B2C 专属事件仅在 B2C 方向出现

## 二、核心系统

### 2.1 抽卡与招募

- [ ] 打开招募界面可见四个岗位池（运营/设计/QA/RD）
- [ ] 点击岗位池后显示该岗位的卡牌列表
- [ ] 点击"抽卡"按钮扣除相应资金
- [ ] 首次抽卡显示角色背景故事弹窗
- [ ] 抽到 SSR 显示专属故事弹窗
- [ ] 抽到卡牌后正确加入背包
- [ ] 抽卡成本随名声变化

### 2.2 卡牌磨损

- [ ] 背包内卡牌正确显示磨损值
- [ ] 谈判失败后卡牌磨损 -1
- [ ] 磨损归零后卡牌消失（触发"离职"提示）
- [ ] 不同星级卡牌初始磨损值正确

### 2.3 克制链系统

- [ ] 运营卡牌克制设计卡牌
- [ ] 设计卡牌克制 QA 卡牌
- [ ] QA 卡牌克制 RD 卡牌
- [ ] RD 卡牌克制运营卡牌
- [ ] 克制关系正确显示胜负提示
- [ ] 非克制关系进行战力比拼

### 2.4 报表与谈判

- [ ] 每季度末正确触发报表谈判
- [ ] 三局两胜制正确执行
- [ ] 谈判胜利：卡牌不损耗
- [ ] 谈判失败：卡牌磨损 -1
- [ ] 谈判点数正确累计
- [ ] OKR 加点正确应用

### 2.5 数值变化

- [ ] To B：满意度正确影响项目进度
- [ ] To B：续约率正确影响下个项目类型
- [ ] To C：DAU 正确影响季度收入
- [ ] To C：LTV 正确影响季度收入
- [ ] B2C：GMV 正确影响季度收入
- [ ] B2C：抽成率正确影响季度收入
- [ ] 每周预算正确扣除基础损耗
- [ ] 负债正确产生利息

## 三、融资与对赌

### 3.1 融资触发

- [ ] 天使轮在 1-3 季度随机触发
- [ ] A 轮在 4-8 季度随机触发
- [ ] B 轮在 9-12 季度随机触发
- [ ] C 轮在 12+ 季度随机触发
- [ ] 融资弹窗正确显示融资金额和选项

### 3.2 接受融资

- [ ] 接受后资金正确增加
- [ ] 接受后名声正确提升
- [ ] 对赌条款正确显示

### 3.3 对赌机制

- [ ] 对赌成功无额外奖励
- [ ] 对赌失败正确扣除名声
- [ ] 对赌失败正确扣除预算

### 3.4 拒绝融资

- [ ] 拒绝后游戏继续正常进行
- [ ] 拒绝后不触发对赌

## 四、图鉴与结局

### 4.1 产品陈列馆

- [ ] 可从主界面打开产品陈列馆
- [ ] To B / To C / B2C 分栏正确显示
- [ ] 已解锁产品显示像素图和脱敏名称
- [ ] 已解锁产品显示三重声音
- [ ] 未解锁产品显示条件差距
- [ ] 条件满足后自动解锁

### 4.2 胜利条件

- [ ] To B：资产≥2000万+5个标杆客户 → 出现上市敲钟选项
- [ ] To C：资产≥2000万+DAU>500万 → 出现上市敲钟选项
- [ ] B2C：资产≥2000万+GMV>10亿 → 出现上市敲钟选项
- [ ] 资产≥1000万+连续8季度盈利 → 出现闷声发财选项
- [ ] 资产≥500万+市场地位达标 → 可能触发被收购事件

### 4.3 失败条件

- [ ] 资金≤0且负债达上限 → 触发破产清算结局
- [ ] To C：DAU=0 → 触发产品凉了结局
- [ ] B2C：纠纷率>30% → 触发平台崩盘结局

### 4.4 结局展示

- [ ] 结局弹窗正常显示
- [ ] 结局文案正确显示（方向对应）
- [ ] 显示结局类型标识
- [ ] 提供重新开始选项
