# 公平事务所 · 开发 TODO 清单

## P0 - 阻塞测试（必须修复后再上线）

- [ ] **新游戏流程中断**：点击"开始游戏"后直接跳转到方向选择，创始人手记弹窗未正确触发
- [ ] **选择方向后黑屏**：选择 To B/To C/B2C 后页面无响应，无法进入游戏主界面
- [ ] **游戏主界面空白**：进入 game.html 后顶部状态栏或主内容区无数据显示
- [ ] **localStorage 数据丢失**：刷新页面后游戏进度全部重置
- [ ] **抽卡功能失效**：点击"抽卡"按钮无响应，或提示"请先选择岗位"
- [ ] **谈判对决无法触发**：到季度末时未出现报表谈判界面
- [ ] **融资事件无法触发**：游戏进行多季度后未出现任何融资弹窗
- [ ] **JSON 配置文件加载失败**：控制台报 404 错误，某个 .json 文件未找到
- [ ] **方向选择后数值初始化错误**：To B 的 satisfaction 未初始化、To C 的 dau 未初始化、B2C 的 gmv 未初始化

## P1 - 影响体验（严重影响玩家体验）

### 新手指引

- [ ] **抽卡系统引导**：首次打开抽卡界面时弹出说明（岗位选择、抽卡消耗、卡牌获得）
- [ ] **谈判对决引导**：首次触发报表谈判时弹出说明（克制链规则、三局两胜、磨损机制）
- [ ] **融资系统引导**：首次触发融资事件时弹出说明（接受/拒绝选项、对赌条款）
- [ ] **产品陈列馆引导**：首次打开图鉴界面时弹出说明（解锁条件、三重声音）
- [ ] **OKR 加点引导**：首次进行 OKR 加点时弹出说明（谈判点数用途、权重影响）

### 周报故事补全

- [ ] **To B 周报故事（10篇）**：每篇包含团队日常/项目吐槽/甲方逸事
- [ ] **To C 周报故事（10篇）**：每篇包含用户反馈/增长数据/竞品动态
- [ ] **B2C 周报故事（10篇）**：每篇包含服务商纠纷/用户投诉/平台运营

### 结局文案

- [ ] **上市敲钟结局**：To B / To C / B2C 三个版本的敲钟文案（现只有占位符）
- [ ] **闷声发财结局**：三个方向的低调退出文案
- [ ] **被收购结局**：三个方向的不同收购方文案（投资机构/大厂/竞争对手）
- [ ] **破产清算结局**：清算现场描述文案
- [ ] **产品凉了结局**：To C 专属凉透文案
- [ ] **平台崩盘结局**：B2C 专属崩盘文案

### 数值与平衡性

- [ ] **To B 收入过低**：当前分阶段回款数值导致资金回笼太慢
- [ ] **To C DAU 增长太慢**：用户基数太小，收入几乎为零
- [ ] **B2C 纠纷率失控**：纠纷率上升太快，难以维持 30% 以下
- [ ] **抽卡成本失衡**：当前抽一次卡的消耗与收入不匹配
- [ ] **融资时机不对**：天使轮触发太早或太晚
