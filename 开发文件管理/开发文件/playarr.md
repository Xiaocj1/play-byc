## 核心数值系统

### 三模式统一数值
- **资金（Budget）**：收入来源（回款/收入/抽成），支出工资、抽卡、事件
- **名声（Fame）**：影响报表奖励、抽卡成本、负债上限、利率
- **负债（Debt）**：可借额度由名声决定，每周利息，资金归零且无法借款时破产

### 项目进度
- **初始值**: 0%
- **最大值**: 100%
- **显示格式**: `XX.XX% (阶段名称·SDLC-0X)`
- **完成动画**: 100%时触发彩虹流动效果

### 甲方满意度（To B）
- **初始值**: 80%
- **范围**: 0-100%
- **失败条件**: 连续3周低于65%

### 团队好感度
- **初始值**: 50%
- **范围**: 0-100%
- **效率buff触发**: >80%时触发

### 方向特定指标

#### To B 模式
| 指标 | 说明 |
|------|------|
| 标杆客户数 | 成功交付的客户数量 |
| 满意度 | 甲方对项目的满意程度 |
| 续约率 | 下个项目是否续约的概率 |

#### To C 模式
| 指标 | 说明 |
|------|------|
| DAU | 日活跃用户数 |
| LTV | 用户生命周期价值 |
| 留存率 | 用户留存情况 |

#### B2C 模式
| 指标 | 说明 |
|------|------|
| GMV | 商品交易总额 |
| 抽成率 | 平台抽取的佣金比例 |
| 纠纷率 | 交易纠纷发生率 |

## 创业方向系统

### 开局三选一
玩家在游戏开始时选择创业方向：
- **To B（企业服务）**：对接企业甲方，分阶段回款
- **To C（消费者应用）**：面向个人用户，DAU驱动收入
- **B2C（平台电商）**：连接服务商与用户，GMV抽成

### 方向影响
- 影响核心指标体系
- 影响任务来源和类型
- 影响结局文案
- 共用资金、名声、负债、抽卡、报表系统

## 报表与谈判对决系统

### 三局两胜制
每季度末进行报表对决，决定下季度 OKR 加点

### 四类卡牌岗位
| 岗位 | 说明 |
|------|------|
| 运营 | 负责增长和用户运营 |
| 设计 | 负责UI/UX设计 |
| QA | 负责质量保证和测试 |
| RD | 负责技术开发 |

### 克制链
```
运营 → 设计 → QA → RD → 运营
```
- 克制方胜利，不损耗卡牌
- 被克制方失败，卡牌磨损 -1
- 磨损归零则卡牌销毁（离职/考公）

### 战力比拼
当双方岗位不存在克制关系时，进行战力比拼：
- 卡牌战力 = 星级 × (1 + 效率加成)
- 战力高者获胜

### 谈判点数
每季度谈判获胜可获得谈判点数，影响下季度 OKR 加点

### 配置文件
`data/cards.json`

## 收入与运营模式

### To B（分阶段回款）
```
收入 = 项目基数 × 阶段比例 × 满意度系数
```
- **阶段比例**：30% → 40% → 30%（3-4-3模式）
- **满意度系数**：0.5 + (满意度 / 100)
- **项目续约**：续约率高可能获得2.0升级项目（进度+30%）

### To C（季度收入结算）
```
季度收入 = DAU × LTV × (季度天数 / 365)
```
- LTV 默认值：1万元
- 季度天数：90天

### B2C（季度收入结算）
```
季度收入 = GMV × 抽成率
```
- 默认抽成率：5%
- GMV 单位：亿元

## 合同与风险系统

### 合同续约机制（仅 To B）
- **续约率**：影响下个项目是2.0升级还是全新项目
- **2.0项目**：进度直接+30%

### 撕合同条件
满足以下任一条件，甲方可能撕毁合同：
- 满意度 < 25%
- 连续两季度进度 < 50%
- 多次硬刚甲方

### 撕合同后果
- 赔偿金扣除
- 名声大降
- 好感度下降
- 甲方黑名单

### To C 风险事件
- 用户流失
- 买量成本飙升
- 监管下架
- 版本被应用商店下架

### B2C 风险事件
- 服务商抗议
- 用户投诉暴增
- 纠纷率过高
- 监管部门约谈
- 竞争对手降价

## 好感度与效率系统

### 效率Buff触发
- **触发条件**: 好感度 > 80%
- **效果**: 效率随机增加 5%-100%
- **持续时间**: 永久（直到好感度降至80%以下）

### 效率计算
```javascript
efficiency = 1 + randomBonus(0.05, 1.0) + buffEffects
```

### 好感度历史追踪
- 保留最近5周的好感度记录
- 用于计算趋势指示（⬆️上升/⬇️下降/➡️持平）

## 结局系统

### 胜利条件

#### 上市敲钟
- **条件**：资产 ≥ 2000万 + 市场地位达标
  - To B：5个标杆客户
  - To C：DAU > 500万
  - B2C：GMV > 10亿

#### 闷声发财
- **条件**：资产 ≥ 1000万 + 连续2年盈利 + 玩家主动拒绝上市

#### 被收购
- **条件**：资产 ≥ 500万 + 市场地位达标 + 触发收购事件

### 失败条件

#### 破产清算
- **条件**：资金 ≤ 0 且 负债已达上限

#### 产品凉了（To C）
- **条件**：DAU = 0

#### 平台崩盘（B2C）
- **条件**：纠纷率 > 30%

### 结局文案风格
- 黑色幽默
- 拒绝温情鸡汤
- 反映创业现实

### 配置文件
`data/endings.json`
