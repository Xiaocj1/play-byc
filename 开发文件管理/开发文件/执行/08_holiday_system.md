# 节假日系统

## 功能描述
引入真实节假日因素，增强游戏沉浸感。不同节日有不同的效果和事件，节假日影响团队状态和工作效率。

## 关键词池
keywords:
  - 节假日系统
  - 季节事件
  - 沉浸感

locked_keywords:
  - 移除节假日系统
  - 所有日子进度相同

emphasis_keywords:
  - 节假日效果参考现有事件强度（士气±3~8，资金±5~30）
  - 必须支持模式差异化

## 数据定义
**季度节假日安排（12周/季度）：**

| 季度 | 游戏周数 | 节假日 | 效果 |
|------|---------|--------|------|
| **Q1** | 第2周 | 元旦 | 士气+3，本周无需支付基础开销 |
| **Q1** | 第4周 | 春节假期 | 进度暂停1周，节后士气+5 |
| **Q1** | 第6周 | 元宵节 | 士气+3，资金-5 |
| **Q2** | 第16周 | 劳动节 | 进度-5%，士气+3 |
| **Q2** | 第23周 | 端午节 | 士气+5，资金-3 |
| **Q3** | 第31周 | 七夕节 | 士气+3 |
| **Q3** | 第36周 | 中秋节 | 士气+5，资金-5 |
| **Q3** | 第39周 | 国庆节 | 进度暂停1周，节后士气+5 |
| **Q4** | 第46周 | 万圣节 | 士气+3 |
| **Q4** | 第50周 | 感恩节 | 士气+5 |
| **Q4** | 第52周 | 圣诞节/跨年 | 士气+5，资金-8 |

**节假日特殊事件示例（春节）：**
```json
{
  "id": "holiday_spring_festival",
  "title": "春节假期",
  "description": "春节到了，团队放假一周。虽然进度会暂停，但大家都很期待新年的到来！",
  "type": "holiday",
  "weekRange": [3, 4],
  "effects": {
    "progress_pause": 1,
    "morale": 10,
    "budget_saving": true
  },
  "options": [
    {
      "text": "安排值班",
      "effects": {"progress": 5, "aisaike": -5, "moganna": -5},
      "weeklyEffect": "部分成员值班，进度有所推进但大家有些疲惫"
    },
    {
      "text": "全员放假",
      "effects": {"morale": 15},
      "weeklyEffect": "大家充分休息，节后干劲十足"
    }
  ]
}
```

**节假日影响机制：**
```
节假日周开始时：
  ├─ 检查是否为节假日周
  ├─ 应用节假日基础效果
  ├─ 触发节假日特殊事件（可选）
  │   └─ 玩家选择应对方式
  └─ 记录节假日日志
```

**模式差异化设计：**

| 模式 | 节假日特殊效果 | 节日事件主题 |
|------|-------------|-------------|
| **ToB** | 春节前回款加速，节后甲方需求爆发 | 年会抽奖、客户拜年、开工红包 |
| **ToC** | 春节下载量激增，国庆应用商店流量翻倍 | 春节运营活动、双十一促销、年终榜单 |
| **B2C** | 春节GMV高峰，双十一商家促销季 | 年货节、618大促、商家年会 |

**涉及文件：**

| `data/direction_config.json` | 增加节假日配置 |
