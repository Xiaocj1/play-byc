# 角色专属季节/节日Buff系统

## 功能描述
为四大核心角色设计专属的季节和节日buff，增加游戏的真实感和趣味性。

## 关键词池
keywords:
  - 角色Buff
  - 季节Buff
  - 节日Buff

locked_keywords:
  - 移除角色专属Buff
  - 所有角色共享相同Buff

emphasis_keywords:
  - Buff效果必须符合角色职业/性格特点
  - 避免重复触发同类型Buff
  - 负面Buff效果不能过强

**Buff触发机制：**
```
每周开始时：
  ├─ 检查当前季节/节日/季度
  ├─ 检查角色是否已有同类型buff（避免重复触发）
  ├─ 根据角色特性触发对应buff
  │   ├─ 应用buff效果到游戏状态
  │   └─ 显示buff提示信息
  └─ 记录到角色状态
```
