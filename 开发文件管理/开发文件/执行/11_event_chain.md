# 突发事件连锁系统

## 功能描述
事件之间产生关联和影响，形成连锁反应，增加游戏的策略深度和真实感。

## 关键词池
keywords:
  - 事件连锁
  - 触发条件
  - 后续事件

locked_keywords:
  - 移除事件连锁机制
  - 所有事件独立触发

emphasis_keywords:
  - 连锁事件必须逻辑连贯
  - 必须支持模式差异化

## 数据定义
**事件连锁机制示例：**
```
触发"服务器宕机"事件 → 若选择"紧急修复" → 触发"加班疲劳"后续事件
触发"用户好评"事件 → 若满意度足够 → 触发"媒体报道"机遇事件
```

**模式差异化连锁表：**

| 模式 | 触发事件 | 连锁事件 | 条件 |
|------|---------|---------|------|
| **ToB** | 客户投诉 | 合同纠纷 | 满意度<50 |
| **ToB** | 项目验收通过 | 客户转介绍 | 满意度>80 |
| **ToC** | 应用商店推荐 | 下载量爆发 | DAU<30万 |
| **ToC** | 负面测评 | 用户流失 | 满意度<40 |
| **B2C** | 商家抗议 | 集体退出 | 纠纷率>30% |
| **B2C** | 头部商家入驻 | 平台升级 | GMV>50亿 |

**连锁事件数据结构（建议）：**
```json
{
  "id": "event_server_down",
  "title": "服务器宕机",
  "type": "crisis",
  "chainCondition": {
    "choice": "紧急修复",
    "triggerEvent": "event_overtime_fatigue"
  }
}
```

**涉及文件：**

| 文件 | 修改内容 |
|------|---------|
| `data/events.json` | 扩展事件数据结构（增加chainCondition字段） |
| `js/game.js` | 事件连锁触发逻辑 |
