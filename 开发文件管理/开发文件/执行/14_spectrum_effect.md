# 光谱特效动画

## 功能描述
为卡牌光谱系统添加视觉特效，增强游戏体验和沉浸感。

## 关键词池
keywords:
  - 光谱特效
  - 视觉动画
  - 协同特效

locked_keywords:
  - 移除光谱特效
  - 纯数值计算无特效

emphasis_keywords:
  - 特效必须对应光谱颜色
  - 提供特效开关（性能优化）

## 数据定义
**光谱颜色定义：**

| 光谱名称 | 颜色代码 | 特效描述 |
|---------|---------|---------|
| 技术光谱 | #3b82f6 | 蓝色数据流特效 |
| 服务光谱 | #ef4444 | 红色品质检测特效 |
| 设计光谱 | #8b5cf6 | 紫色创意光芒特效 |
| 运营光谱 | #22c55e | 绿色人气波纹特效 |
| 资金光谱 | #eab308 | 黄色金币闪烁特效 |
| 特殊光谱 | #a855f7 | 紫色神秘漩涡特效 |

**协同特效类型：**

| 协同类型 | 视觉特效 | 动画描述 |
|---------|---------|---------|
| 职业协同 | 光谱桥梁 | 员工卡牌与谈判卡牌之间出现光谱桥梁动画 |
| 功能协同 | 双重漩涡 | 两张同光谱卡牌周围出现双重漩涡特效 |
| 跨光谱组合 | 彩虹桥 | 四种光谱卡牌同时释放，形成彩虹桥特效 |
| 职业专精 | 光环扩散 | 同职业员工卡牌周围出现光环扩散特效 |

**特效数据结构（建议）：**
```json
{
  "spectrum": "tech",
  "color": "#3b82f6",
  "effectType": "bridge",
  "animationDuration": 1.5,
  "enable": true
}
```

**涉及文件：**

| 文件 | 修改内容 |
|------|---------|
| `css/modals.css` | 添加光谱特效CSS动画 |
| `js/game.js` | 特效触发逻辑 |
| `js/merchant_game.js` | 招商会小游戏特效 |

## 负面影响评估
risks:
  - risk: "特效过多导致性能问题"
    severity: 中
    mitigation: "提供特效开关，低配置设备自动关闭特效"
  - risk: "特效过于花哨，影响游戏体验"
    severity: 低
    mitigation: "特效设计简洁，不遮挡核心信息"
