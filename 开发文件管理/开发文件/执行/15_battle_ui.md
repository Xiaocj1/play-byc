# 战斗UI + 耐久度显示

## 功能描述
优化战斗UI，添加光谱特效显示和卡牌耐久度显示，提升用户体验。

## 关键词池
keywords:
  - 战斗UI
  - 耐久度显示
  - 光谱特效

locked_keywords:
  - 移除耐久度显示
  - 使用旧版UI

emphasis_keywords:
  - 耐久度必须清晰显示
  - UI必须支持光谱特效
  - 提供特效开关

## 数据定义
**UI元素定义：**

| UI元素 | 位置 | 显示内容 |
|---------|------|---------|
| 卡牌耐久度 | 卡牌右上角 | 当前耐久度/初始耐久度（如 7/10） |
| 光谱标识 | 卡牌左上角 | 光谱图标+颜色边框 |
| 协同提示 | 卡牌下方 | 协同类型+效果加成 |
| 报废警告 | 卡牌中央 | 耐久度≤2时显示红色警告 |

**耐久度颜色规则：**

| 耐久度范围 | 颜色 | 描述 |
|---------|------|------|
| 80%-100% | 绿色 | 状态良好 |
| 50%-79% | 黄色 | 需要注意 |
| 20%-49% | 橙色 | 警告状态 |
| 0%-19% | 红色 | 即将报废 |

**涉及文件：**

| 文件 | 修改内容 |
|------|---------|
| `css/modals.css` | 添加耐久度显示样式、光谱特效样式 |
| `js/game.js` | 战斗UI逻辑、耐久度更新 |
| `js/merchant_game.js` | 招商会小游戏UI |

## 验收标准
- [ ] 卡牌耐久度正确显示在右上角
- [ ] 耐久度颜色规则正确应用（绿→黄→橙→红）
- [ ] 光谱标识正确显示（图标+颜色边框）
- [ ] 协同提示正确显示（协同类型+效果加成）
- [ ] 耐久度≤2时显示红色警告
- [ ] 报废卡牌正确显示（灰色+报废标识）
- [ ] 提供特效开关，可关闭所有特效
- [ ] UI响应式设计，支持不同分辨率
