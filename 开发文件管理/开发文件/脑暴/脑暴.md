### 3.3 数值平衡建议

**1. 持续效果折算公式**

季节Buff是持续效果（2-4周），需折算为等效单次事件效果：

```
持续效果总影响 = 单次效果 × 持续时间

例：
- PRD原案：进度+3%/周，持续2周 = 总+6%
- 现有事件：进度+5%~+8%（单次）
- 评估：持续效果总影响应 ≤ 单次的2倍
- 建议：进度+1%~+2%/周（总+2%~+4%）
```

**2. 节假日效果上限**

为防止节假日过于强大，建议设置上限：

| 效果类型 | 单次上限 | 季度累计上限 |
|---------|---------|---------|
| 士气 | +8 | +20 |
| 进度 | +10% | +25% |
| 资金 | -30 | -60 |

**3. 动态事件次数的平衡性**

PRD §4.2 提案：
- 高士气（≥80）：2次事件/周
- 正常状态：3次事件/周
- 低士气（≤40）：4次事件/周

**问题**：高士气时事件次数减少，但每次事件的效果不变，导致周进度反而降低。

**建议修改**：

```markdown
### 4.2 优化方案：基于状态的动态次数（修订版）

| 游戏状态 | 每周事件次数 | 每次事件效果乘数 | 周进度预期 |
|---------|-------------|----------------|---------|
| 高士气（≥80） | 2次 | ×1.5 | 2 × 5% × 1.5 = 15% |
| 正常状态 | 3次 | ×1.0 | 3 × 5% × 1.0 = 15% |
| 低士气（≤40） | 4次 | ×0.8 | 4 × 5% × 0.8 = 16% |

注：高士气时效率提升（效果乘数×1.5），低士气时效率降低（×0.8）
```

修改 `js/game.js` 的 `renderEvent()` 函数：

```javascript
// 修改前（第1342行）：
function renderEvent() {
    // ...
    const availableEvents = events.filter(event => {
        if (!event.direction) return true;
        return event.direction === direction;
    });
    // ...
}

// 修改后：
function renderEvent() {
    // ...
    const availableEvents = events.filter(event => {
        // 方向过滤
        if (!event.direction) return true;
        if (event.direction !== direction && event.direction !== 'all') return false;
        
        // 触发条件判断
        if (event.triggerCondition) {
            return shouldTriggerEvent(event);
        }
        
        return true;
    });
    // ...
}

function shouldTriggerEvent(event) {
    const condition = event.triggerCondition;
    
    // 概率触发
    if (condition.probability) {
        if (Math.random() > condition.probability) return false;
    }
    
    // 周数范围
    if (condition.minWeek && gameState.week < condition.minWeek) return false;
    if (condition.maxWeek && gameState.week > condition.maxWeek) return false;
    
    // 满意度条件
    if (condition.satisfactionBelow && gameState.satisfaction >= condition.satisfactionBelow) return false;
    if (condition.satisfactionAbove && gameState.satisfaction <= condition.satisfactionAbove) return false;
    
    // 进度里程碑
    if (condition.progressMilestone && gameState.progress < condition.progressMilestone) return false;
    
    // 节假日临近
    if (condition.holidayNear) {
        if (!isHolidayNear(condition.holidayNear)) return false;
    }
    
    // 季节条件
    if (condition.season) {
        const currentSeason = getCurrentSeason();
        if (!condition.season.includes(currentSeason)) return false;
    }
    
    return true;
}
```

```javascript
function shouldAdvanceWeek() {
    const eventCount = getWeeklyEventCount();
    return gameState.currentEventIndex % eventCount === 0;
}

function getWeeklyEventCount() {
    const satisfaction = gameState.satisfaction;
    const morale = gameState.morale || 50;
    
    // 高士气：效率提升，事件次数减少
    if (satisfaction >= 80 || morale >= 80) {
        return 2;

    // 低士气：问题多，事件次数增加

        return 1;
```

**3. 季节判断函数（§九）**

```javascript
function getCurrentSeason() {
    const week = gameState.week;
    const quarter = Math.floor((week - 1) / 12) + 1;
    
    // Q1: 春季（第1-12周）
    // Q2: 夏季（第13-24周）
    // Q3: 秋季（第25-36周）
    // Q4: 冬季（第37-48周）
    
    if (quarter === 1) return 'spring';
    if (quarter === 2) return 'summer';
    if (quarter === 3) return 'autumn';
    if (quarter === 4) return 'winter';
    
    return 'spring'; // 默认春季
}

function isHolidayNear(weeksBefore) {
    const holidays = [
        { week: 2, name: 'new_year' },
        { week: 4, name: 'spring_festival' },
        { week: 6, name: 'lantern_festival' },
        { week: 16, name: 'labor_day' },
        { week: 23, name: 'dragon_boat' },
        { week: 31, name: 'qixi' },
        { week: 36, name: 'mid_autumn' },
        { week: 39, name: 'national_day' },
        { week: 46, name: 'halloween' },
        { week: 50, name: 'thanksgiving' },
        { week: 52, name: 'christmas' }
    ];
    
    for (const holiday of holidays) {
        if (Math.abs(gameState.week - holiday.week) <= weeksBefore) {
            return true;
        }
    }
    
    return false;
}
```

function checkEfficiencyBuffs() {
    const currentSeason = getCurrentSeason();
    const currentHoliday = getCurrentHoliday();
    
    data.characters.characters.forEach(character => {
        const characterId = character.id;
        
        // 检查季节触发

                buff.trigger.season === currentSeason &&

}
